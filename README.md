# discordio

Простая закрытая голосовая комната для друзей: голос, текстовый чат и демонстрация экрана прямо в браузере. Сервер маленький (Node.js) и запускается у тебя в WSL, арендовать ничего не нужно, всё бесплатно.

Голос и видео идут напрямую между браузерами (WebRTC). Сервер только знакомит участников друг с другом и пересылает сообщения чата, поэтому нагрузки на твой компьютер почти нет.

## Что умеет

- Комната по ссылке и паролю. Первый, кто зашёл, задаёт пароль; комната исчезает, когда все вышли.
- До 8 человек (меняется переменной `MAX_PEERS`).
- Текстовый чат (история хранится, пока комната жива).
- Демонстрация экрана или окна, со звуком (в Chrome/Edge на Windows), три пресета качества.
- Настройки микрофона:
  - выбор микрофона и динамиков/наушников;
  - шумоподавление: RNNoise (нейросеть, работает прямо в браузере), встроенное браузерное или выключено;
  - эхоподавление и автоматическая регулировка громкости;
  - громкость микрофона до 200%;
  - индикатор уровня и порог голосовой активации;
  - push-to-talk на любую клавишу или боковую кнопку мыши, с задержкой отпускания;
  - «Проверить микрофон»: слышишь себя уже с обработкой.
- Громкость каждого участника отдельно (запоминается по имени).
- Mute и deafen (Ctrl+Shift+M, Ctrl+Shift+D), индикатор «кто говорит», пинг до каждого.

## Запуск в WSL

1. Поставь Node.js 18+ (один раз):

   ```bash
   curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
   sudo apt install -y nodejs
   ```

2. Скачай проект и запусти:

   ```bash
   cd discordio
   npm install
   npm start
   ```

3. Открой в браузере на Windows `http://localhost:3000`. Уже можно зайти и проверить микрофон.

Друзьям нужна **https**-ссылка: браузеры дают доступ к микрофону только по https (или на localhost). Её даёт один из бесплатных туннелей ниже. Выбери любой.

## Как пустить друзей

### Вариант А. Tailscale Funnel (стабильная ссылка, рекомендую)

Друзьям ничего ставить не надо, ссылка постоянная, вида `https://имя-пк.tailXXXX.ts.net`.

1. Установи Tailscale на Windows с https://tailscale.com/download и войди (бесплатный личный план).
2. Пока `npm start` работает в WSL, открой PowerShell в Windows и выполни:

   ```powershell
   tailscale funnel 3000
   ```

   В первый раз команда покажет ссылку, чтобы включить HTTPS и Funnel для твоей сети: открой её и подтверди.
3. Команда напечатает адрес. Скинь друзьям ссылку `https://…ts.net/#имя-комнаты` и отдельно пароль.

Чтобы туннель работал в фоне: `tailscale funnel --bg 3000`, выключить: `tailscale funnel --https=443 off`.

Если все друзья тоже в Tailscale, вместо `funnel` можно использовать `tailscale serve 3000`: тогда комната видна только внутри вашей сети, а не всему интернету.

### Вариант Б. Cloudflare Quick Tunnel (без регистрации)

Работает за минуту, но адрес случайный и меняется при каждом запуске.

```bash
# один раз, в WSL
curl -L -o cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
sudo dpkg -i cloudflared.deb

# каждый раз, во втором окне WSL, пока работает npm start
cloudflared tunnel --url http://localhost:3000
```

В выводе будет адрес `https://что-то-случайное.trycloudflare.com`, его и отправляй друзьям.

## Настройки сервера

Переменные окружения (необязательно):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | порт сервера |
| `MAX_PEERS` | `8` | максимум людей в комнате |
| `TURN_URL`, `TURN_USER`, `TURN_PASS` | нет | свой TURN-сервер, если у кого-то не соединяется (см. ниже) |

Пример: `PORT=8080 npm start`.

## Что ограничено

- **Связь напрямую.** Обычно соединение устанавливается через бесплатные STUN-серверы Google и Cloudflare. У небольшой части провайдеров (жёсткий NAT, некоторые мобильные сети) прямое соединение не получится, и такой участник будет висеть в «соединяю…». Лечится TURN-сервером, но бесплатного без своего сервера с открытым портом нет, поэтому по умолчанию его нет. Если все в Tailscale (`tailscale serve`), эта проблема почти исчезает: браузеры соединяются через сеть Tailscale.
- **Каждый шлёт поток каждому.** На 4–8 человек голосу хватает любого интернета. Демонстрация экрана тяжелее: при 7 зрителях в 720p нужно около 10 Мбит/с исходящего, в 1080p60 около 40. Если тормозит, понижай качество.
- **Push-to-talk работает, только когда окно браузера активно.** Браузер не умеет ловить клавиши, пока ты в игре. Для игр удобнее голосовая активация с порогом и RNNoise.
- **Браузеры.** Лучше всего Chrome и Edge. В Firefox работает, но звук экрана не передаётся. Выбор динамиков есть в Chrome, Edge и новых Firefox. Safari не проверял.
- **Звук системы при демонстрации экрана** доступен в Chrome/Edge на Windows (галочка «Поделиться звуком»). При показе одной вкладки передаётся звук этой вкладки.
- Громкость участника регулируется от 0 до 100%, без усиления.
- Комнаты живут в памяти: после перезапуска сервера все просто заходят заново.
