# discordio ♥

Закрытая голосовая комната для друзей: голос, камера, демонстрация экрана и чат. Есть веб-версия и приложение для Windows. Сервер маленький (Node.js), запускается у тебя локально в WSL. Арендовать ничего не нужно, всё бесплатно.

Голос и видео идут напрямую между участниками (WebRTC). Сервер только знакомит их друг с другом и пересылает чат, поэтому нагрузки на твой компьютер почти нет.

## Что умеет

- Комната по ссылке и паролю. Первый, кто зашёл, задаёт пароль; комната исчезает, когда все вышли. До 8 человек (`MAX_PEERS`).
- Голос, вебкамера (360p, чтобы не грузить сеть), демонстрация экрана или окна со звуком, текстовый чат.
- Аватарки (ужимаются до 128×128).
- Микрофон: выбор устройств, шумодав RNNoise (нейросеть прямо в клиенте), эхоподавление, автогромкость, громкость до 200%, порог голосовой активации с индикатором, push-to-talk на клавишу или боковую кнопку мыши, «Проверить микрофон».
- Громкость каждого участника и «заглушить для себя».
- Mute и deafen (Ctrl+Shift+M, Ctrl+Shift+D).
- Подсказка «ты говоришь, а микрофон выключен», уведомления о сообщениях, кнопка «тыкнуть» друга.
- Оформление в стиле цундере. Светлая и тёмная тема по настройке системы.

## Сервер: запуск в WSL

1. Поставь Node.js 18+ (один раз):

   ```bash
   curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
   sudo apt install -y nodejs
   ```

2. Запусти:

   ```bash
   cd discordio
   npm install
   npm start
   ```

3. Открой `http://localhost:3000` в браузере на Windows и проверь, что всё работает.

Друзьям нужна **https**-ссылка (иначе браузер не даст микрофон). Её даёт один из бесплатных туннелей.

### Вариант А. Tailscale Funnel (постоянная ссылка, рекомендую)

1. Установи Tailscale на Windows с https://tailscale.com/download и войди (бесплатный личный план).
2. Пока `npm start` работает в WSL, в PowerShell на Windows:

   ```powershell
   tailscale funnel --bg 3000
   ```

   В первый раз команда даст ссылку, чтобы включить HTTPS и Funnel: открой и подтверди.
3. Адрес будет вида `https://имя-пк.tailXXXX.ts.net`. Он постоянный. Выключить: `tailscale funnel --https=443 off`.

### Вариант Б. Cloudflare Quick Tunnel (без регистрации, адрес каждый раз новый)

```bash
curl -L -o cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
sudo dpkg -i cloudflared.deb
cloudflared tunnel --url http://localhost:3000
```

### Настройки сервера

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | порт |
| `MAX_PEERS` | `8` | максимум людей в комнате |
| `DESKTOP_DOWNLOAD_URL` | релизы GitHub | куда ведёт `/download`, если в `downloads/` нет установщика |
| `TURN_URL`, `TURN_USER`, `TURN_PASS` | нет | свой TURN-сервер, если у кого-то не соединяется |

## Приложение для Windows

Это то же самое, что веб-версия, плюс:

- push-to-talk работает везде, даже когда ты в игре;
- сворачивается в трей, а не закрывается, и может запускаться вместе с Windows;
- своё окно выбора экрана или окна, со звуком компьютера;
- ссылки «Открыть в приложении» (`discordio://адрес/#комната`).

### Как друзьям его поставить

Проще всего раздать установщик прямо с твоего сервера:

1. Положи `discordio-Setup-<версия>.exe` в папку `downloads/` рядом с `server.js`.
2. Друзья открывают `https://твой-адрес/download` (на странице входа в Windows есть ссылка «Приложение для Windows»), скачивают и запускают. Установка в один клик, без прав администратора.
3. При первом запуске приложение спросит адрес сервера: вставляют тот же `https://…`.

Если `downloads/` пустая, `/download` ведёт на страницу релизов GitHub.

Установщик без цифровой подписи (она платная), поэтому Windows покажет синее окно SmartScreen: «Подробнее» → «Выполнить в любом случае».

### Где взять установщик

**Через GitHub (ничего не ставить себе).** В репозитории есть сборка `.github/workflows/desktop.yml`. Поменяй версию в `desktop/package.json`, затем:

```bash
git tag v0.2.0
git push origin v0.2.0
```

Через 5–10 минут установщик появится в Releases. Для публичного репозитория это бесплатно; для приватного тратит бесплатные минуты GitHub Actions (сборка на Windows занимает около 10 из 2000 в месяц). Учти: если репозиторий приватный, друзья не смогут скачать файл из Releases, тогда раздавай через `downloads/`.

**Собрать самому на Windows** (нужен Node.js для Windows):

```powershell
cd desktop
npm install
npm run dist
```

Готовый файл: `desktop/dist/discordio-Setup-<версия>.exe`.

## Что ограничено

- **Связь напрямую.** У небольшой части провайдеров (жёсткий NAT) прямое соединение не получится, и человек будет висеть в «соединяю…». Лечится TURN-сервером, но бесплатного без своего сервера с открытым портом нет. Если все в Tailscale (`tailscale serve 3000` вместо funnel), проблема почти исчезает.
- **Каждый шлёт поток каждому.** Голосу хватит любого интернета. Камера ~0,45 Мбит/с на каждого зрителя, экран 720p ~1,5 Мбит/с, 1080p60 ~6. На 7 зрителей умножай на 7.
- **Ресурсы приложения.** В звонке около 300–350 МБ памяти: это цена встроенного Chromium. Веб-версия во вкладке уже открытого браузера дешевле. Пока окно свёрнуто, интерфейс не опрашивает статистику, а вся обработка звука идёт в отдельном аудиопотоке.
- **Push-to-talk в браузере** работает, только пока окно активно. В приложении — везде.
- **Звук компьютера при демонстрации в приложении** захватывает весь звук системы, включая голоса друзей, поэтому они могут услышать себя. Включай галочку только для игр и видео.
- **Браузеры.** Лучше всего Chrome и Edge. В Firefox нет звука при демонстрации экрана.
- Громкость участника 0–100%, без усиления. Комнаты живут в памяти: после перезапуска сервера все просто заходят заново.
